Подключение TikTok

TikTok разрешил доступ. Осталось передать этот одноразовый код публикатору:

скопировано ✓

  1. Откройте Actions → «TikTok: подключение».
  2. Нажмите Run workflow, вставьте код в поле code и нажмите зелёную кнопку Run workflow.
  3. Код действует несколько минут и срабатывает один раз — если не успели, просто войдите в TikTok заново.

TikTok не выдал доступ:

Попробуйте войти ещё раз по ссылке из инструкции.

Эта страница открывается автоматически после входа в TikTok.
