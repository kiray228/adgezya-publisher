Условия использования

Приложение «Adgezya Posting» · ТОО «Адгезия», г. Шымкент, Казахстан · действуют с 30.09.2026

«Adgezya Posting» — внутренний инструмент ТОО «Адгезия» для публикации контента компании в её собственных аккаунтах TikTok, Instagram и Threads. Пользоваться приложением могут только уполномоченные сотрудники компании.

Правила

  • Публикуется только контент, на который у компании есть права, в соответствии с правилами сообщества каждой платформы.
  • Каждая публикация проходит согласование ответственным сотрудником компании.
  • Приложение не используется для спама, накрутки, сбора данных других пользователей или рассылок.

Ответственность

Компания отвечает за содержание публикуемых материалов. Сервис предоставляется «как есть» для внутренних нужд компании.
